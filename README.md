# Day 32 - REST API Design, Versioning & Status Codes

5 small, independent, easy-to-understand Express programs.

## Running the Programs
Run `npm install` first, then start any program:

```bash
npm run prog1 # REST Principles & Versioning (/api/v1/)
npm run prog2 # Success Status Codes (200, 201, 204)
npm run prog3 # Client Error Status Codes (400, 404, 409)
npm run prog4 # Auth Status Codes (401 Unauthorized vs 403 Forbidden)
npm run prog5 # Internal Server Error (500) & Error Response Standard
```
